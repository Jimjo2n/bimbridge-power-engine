# Benchmark records

No private incoming response dumps or model-specific scripts are distributed here.

A new record should include: source commit, Revit/runtime versions, fixture provenance and hash, workload and selected scope, equivalent inputs/outputs, transport, cold/warm conditions, execution order, repetitions, median/p95, correctness checks, rollback verification, calls, measured versus estimated tokens, failures and limitations.

Distinguish developer-reported results, independently reviewed arithmetic, locally reproduced tests and future targets. Store only synthetic/public-fixture scripts and sanitized results. See [methodology](../docs/performance/BENCHMARKS.md).
