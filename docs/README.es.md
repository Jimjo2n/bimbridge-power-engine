# BIMBRIDGE – Power Engine

Integración de IA y automatización BIM para Revit. C# mantiene el núcleo y la API de Revit; Rust procesa geometría y Python documentos.

El candidato actual sigue en 0.9.0 con aceptación nativa pendiente. Los nombres internos PDI se conservan para no romper referencias. El repositorio es privado inicialmente y su publicación pública exige confirmación explícita del propietario.

Consulta el [índice](INDEX.md), la [guía de desarrollo](DEVELOPMENT.md), la [arquitectura](0.9.0/POWER_ENGINE_ARCHITECTURE.md) y el [proceso de releases](RELEASING.md). La licencia elegida para el código propio es GPL-3.0-only.
