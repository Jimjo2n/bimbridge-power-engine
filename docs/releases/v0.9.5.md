## Release notes

### Updating

- **From 0.9.4:** use the Update button on the BIMBRIDGE tab or run `Bimbridge.Setup.exe`. Your data and settings are kept.
- **From 0.9.3 or earlier:** run `Bimbridge.Setup.exe` once by hand (see the 0.9.4 notes). The installer migrates your data and configuration.
- **Before updating:** finish or cancel paused tasks. Agents should use the English vocabulary; the Spanish input aliases still work in this version and will be removed after 0.9.5.

### What's new

- **Copy selection ID.** Select elements in Revit (for example 3 conduits and a receptacle), press *Copy selection ID* on the BIMBRIDGE tab and paste into Claude or Codex. The pasted text gives the AI everything it needs: the document, the categories, the ids and a `$sel-…` reference. Every BIMBRIDGE command accepts the reference (queries, plans, geometry checks, audits and tools), from any conversation while Revit is open. If a reference has expired, the AI is told to ask you to copy it again.
- **Everything in English.** Code, documentation, UI, MCP commands, arguments, statuses and guides are now in English. Old Spanish input from existing prompts and agents is still accepted in this version. Data saved by 0.9.3/0.9.4 still loads, and existing idempotency keys still match.
- **New brand look.** The palette is red, black and white, and the product is shown as just "BIMBRIDGE" in Revit, the installer and the MCP server.
- **A ribbon where everything is useful.** *Authorize tasks* shows how many requests are waiting for you. The duplicate *Block C# injection* button was removed; that control stays in Settings, with confirmation.
- **Fixes found while reviewing the translation:**
  - inch input (`pulg`);
  - connector `flow=`;
  - geometry checks against ceilings vs roofs;
  - user-entered values such as "Sí" are never translated;
  - legacy installer switches still work (`/actualizar`, …).

### Known changes

- **Your own recipes:** recipes written for the Spanish scripting API of 0.9.x must be renamed (`Receta` → `Recipe`, `Unidad` → `Unit`, `ctx.Omitir` → `ctx.Skip`, …). See the table in `docs/RECIPES.md`. Bundled recipes are already updated.
- **AgentHost (alpha):** plan folders from 0.9.x report `plan_legacy_format`. Finish them before updating.
- **No update ZIP:** this release ships no update ZIP, because CI has no signing key. Use the installer.
