# BIMBRIDGE 0.9.4 experimental

## Updating from 0.9.x — one manual step

This release renames the product internals to BIMBRIDGE. Earlier versions only recognize the old installer name, so run **Bimbridge.Setup.exe** once by hand (double-click). The installer migrates your data and configuration, removes the previous add-in only after the new one installs successfully, re-registers Claude Code and Codex as `bimbridge` (keeping your agent alias), and rewrites your saved recipes and scripts. Before updating, finish or cancel paused tasks. Afterwards, re-create Claude Code permission rules for `mcp__bimbridge__*` and re-assign Revit shortcuts / Quick Access Toolbar entries for BIMBRIDGE buttons. Restart open Claude/Codex conversations. The update ZIP in this release is unsigned (no signing key in CI); use the installer.

## What's new since 0.9.3

- Redesigned installer and add-in interface: shared design system, Status and Queue windows that show what matters at a glance with details one click away, ribbon buttons that animate briefly only when their state changes, new Settings window (pause, apply mode, dynamic C# with one shared confirmation, motion automatic/reduced), safer uninstall (Enter cancels).
- Dispatch diagnostics: `plan timing=true` and `commit timing=true` break down Revit queue wait, Revit thread time, ExternalEvent.Raise result, visits before start and commit phases; `revit_ocupado` responses include dispatch data. Purpose: find the cause of 1-3 s latency spikes before changing dispatch.
- Task safety with two Revit instances: cancel/note/reconcile/archive refuse when another Revit holds the task lease; a runner that lost its lease no longer overwrites the new owner's task record.
- Document worker memory limit enforced live (every 250 ms) on Windows; a heavy failed job no longer causes the next small job to be discarded.
- Faster duplicate-point detection in the Rust geometry kernel for dense inputs (e.g. 18.7 → 10.4 ms median for 20,000 2D points in groups of 200).
- Renamed everywhere to BIMBRIDGE (projects, MCP server `bimbridge`, English `BIMBRIDGE_*` environment variables, data folders) with automatic migration.
- CI: actions/setup-dotnet 6.1, actions/setup-python 7.1.

## Validation

Offline: build.ps1 for all Revit years, 834+ .NET tests, Rust tests, CI green. Not yet verified in a live Revit session: the redesigned windows, ribbon animation smoothness, the upgrade from a real 0.9.3 install, and the new timing measurements (planned native A/B run).

## Known flaky tests

A few load-sensitive tests (lease TTL, compile cache concurrency) can fail only in the full parallel run; they pass in isolation.
