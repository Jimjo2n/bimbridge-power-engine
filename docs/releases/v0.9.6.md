## Release notes

Patch release on top of 0.9.5. Everything in the 0.9.5 notes still applies.

### Fixed

- **Installer:** the endless "file in use" dialog at the end of an update is gone. After installing, the installer sends older installer copies in Downloads/Desktop to the Recycle Bin; it tried to recycle itself when it ran from there, and Windows refused because the file was open. It now skips the installer that is running.

### Updating

- Run `Bimbridge.Setup.exe` (0.9.5 can also update through the BIMBRIDGE tab). Your data and settings are kept.
- If you saw the dialog on 0.9.5, the install itself had finished; only the cleanup of the old copy failed. You can delete that copy by hand.
- No update ZIP is attached, because CI has no signing key.
