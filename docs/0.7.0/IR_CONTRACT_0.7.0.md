# IR contract (schema 2) — 0.7.0-alpha1

Real example generated by `agenthost documento evidencia/especificacion_ejemplo.txt` → `evidencia/plan_desde_documento.json` (log in `evidencia/documento_pipeline.log`).

## Plan (untrusted input)
| Field | Required | Notes |
|---|---|---|
| `ir` | yes | `2` |
| `objetivo` | yes | text |
| `documento.clave`, `documento.huella` | yes | must match the model; otherwise ⇒ `documento_distinto` |
| `unidades.longitud` | yes | `mm`, `m`, `ft`, `in` |
| `coordenadas` | yes | `interno_revit` / `compartidas` |
| `fuentes[]` | if ops have `fuente` | `id`, `nombre`, `sha256` |
| `operaciones[]` | yes | see below |

## Operation
`id` (computed by the system), `operacion` (catalog), `alcance`, `parametros`, `depende_de[]` (ids or `#n`), `precondiciones[]` (`objetivos` min/max), `resultado_esperado`, `permitir_vacio`, `reintentos` (0–3), `fuente` {fuente, pagina, seccion, requisito, cita}.
**Not declarable** (rejected with `campo_no_declarable`): `autorizacion`, `postcondiciones`, `idempotencia`, `estado`.

## Catalog
| operation | writes | parameters | scope | derived authorization | postcondition |
|---|---|---|---|---|---|
| consultar | no | categoria | — | — | elements |
| fijar_parametro | yes, convergent | parametro, valor, unidades, tolerancia | categoria, nivel | escritura_modelo | all targets with the value ± tolerance |
| verificar_qc | no | receta (qc_manifiesto, montaje_soportes) | nivel | — | deviations = 0 |

## Execution state (mutable, in `diario.jsonl`)
States: validada, en_ejecucion, ejecutada, verificada, fallida, requiere_verificacion, requiere_reconciliar, bloqueada, cancelada.
Error classes: precondicion, sin_objetivos, rechazo_backend, transitorio, verificacion, efecto_parcial, efecto_incierto, evidencia_insuficiente, dependencia, cancelacion, documento_distinto, estado_corrupto, plan_en_uso, interno.

## CLI exit codes
0 all verified · 1 error · 2 there are exceptions · 3 plan in use · 4 lease lost · 5 paused · 64 usage.
