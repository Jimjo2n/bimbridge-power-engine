The license permits use, modification and redistribution under its terms. Preserve applicable copyright and license notices and identify modifications as required. A source archive must correspond to the binary being distributed, including relevant build material.

GPL does not impose a universal requirement to publish modifications used exclusively internally. The authoritative terms are [GNU GPLv3](https://www.gnu.org/licenses/gpl-3.0.html), particularly sections 4–6 for conveying modified source and non-source forms.

## Packages

A release review must associate each installer with its source commit, source archive, build procedure, dependency inventory, notices and checksums. Hashes do not replace licensing or acceptance evidence. A private development repository is not a substitute for obligations that apply when binaries are conveyed.

Do not attach Autodesk API reference DLLs, SDK material, signing keys or unrelated proprietary components without sufficient redistribution rights. Installed Revit or reference NuGet packages are build inputs; inspect the actual package contents before distribution.
