# 0009 — GPL version 3 only

Status: recorded during repository preparation, 2026-11-10. This is a source-backed record, not a claim about the date of an original design discussion.

## Context
The project owner selected GNU GPL v3 for original code.

## Decision
Apply SPDX GPL-3.0-only, preserve the complete license and keep dependency notices separate.

## Alternatives
Permissive and other copyleft licenses have different redistribution terms. GPL-3.0-only is the declared project selection; no alternative license is applied to original code by this record. Third-party terms remain separate.
## Consequences
Distribution requires a corresponding-source and notices review. This does not relicense Autodesk inputs or other dependencies.

## Evidence
`LICENSE` in the verified a291cc6 source baseline, together with the current sanitized import.
