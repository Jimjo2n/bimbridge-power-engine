# Code of conduct

Contributors and maintainers are expected to communicate respectfully, discuss technical evidence, welcome questions and protect private information.

Harassment, discriminatory abuse, threats, deliberate disclosure of private data and repeated disruption are unacceptable. Criticism should address behavior or technical decisions rather than personal characteristics.

Report concerns privately to @Jimjo2n through an established private channel. If no private channel is available, request contact without disclosing incident details publicly. No unverified email address is designated.

The maintainer may remove inappropriate content, request changes, restrict participation or refer a matter to GitHub's reporting mechanisms. Decisions should be proportionate, consider context and protect reporters' privacy. These expectations apply to project-controlled collaboration spaces.
